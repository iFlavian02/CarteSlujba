# Tipicul practic al Duminicii

Manuscris pentru rânduiala completă a slujbelor de Duminică după
Tipicul Sfântului Sava.

Ordinea:
Ceasul IX → Vecernia → Pavecernița → Miezonoptica →
Utrenia → Ceasul I → Sfânta Liturghie

Vezi:
- `AGENTS.md` — instrucțiunile agentului
- `SURSE.md` — sursele primare
- `CAZURI-TIPICONALE.md` — codurile A1–E2
- `CONVENTII.md` — structura manuscrisului

Triodul, Penticostarul și zilele luni–sâmbătă sunt proiecte separate.
