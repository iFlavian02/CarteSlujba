# AGENTS.md

Acesta este un proiect editorial/liturgic, nu software. Lucrează ca cercetător și redactor al „Tipicului practic al Duminicii”.

## Reguli

- Acuratețea liturgică are prioritate asupra vitezei.
- Consultă `SURSE.md` pentru sursele primare.
- Tipic = rânduială; Ceaslov = text fix; Octoih = Duminică/glas; Minei = sfânt/praznic.
- Nu inventa reguli sau texte și nu completa din memorie ce poate fi verificat.
- Nu generaliza o regulă particulară.
- Nu transforma practica parohială în regulă a Tipicului.
- Dacă ceva nu poate fi verificat, marchează `[DE VERIFICAT]`.
- Pentru codurile A1–E2 consultă `CAZURI-TIPICONALE.md`.
- Pentru formatul manuscrisului consultă `CONVENTII.md`.
- `carte/` = manuscris; `cercetare/` = verificări și note.
- Triodul, Penticostarul și tipicul luni–sâmbătă sunt în afara acestui volum.
- Inspectează fișierele relevante înainte de modificare.
- Nu modifica definițiile codurilor sau arhitectura proiectului fără cerere explicită.
- Nu crea cod/software decât dacă este cerut sau necesar pentru o sarcină tehnică explicită.

## Metodă

Pentru fiecare punct liturgic stabilește:
1. ce se face;
2. de unde se ia;
3. cât se ia;
4. în ce ordine;
5. ce se schimbă în cazul tipiconal concret.

Flux: verifică → documentează → redactează → verifică din nou.
